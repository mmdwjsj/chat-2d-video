# 需求整理

> 整理时间：2026-11-20
> 依据：项目现状 + 用户明确表达的目标效果。本文只定义「要什么」，技术方案见 `ANIMATION_TECH_PLAN.md`。

## 1. 目标效果（一句话）

把「一个主题 / 一份剧本」变成一集**真正会演的 2D 动画竖屏短片**（中泰双语、导出 MP4）：人要有表演，场景要有空间，换人换景不换代码。

拆成五条：

1. **人物会演**：每个人物有自己的动作库，坐→站、起身、走路、转身、递东西等肢体动作逐帧演出来；嘴型只是其中一层。
2. **场景有空间**：背景分层（远景/中景/近景/前景）并带锚点（沙发、门、灶台），随人物移动产生视差与遮挡；「从客厅走到厨房」是真走过去，不是切一张新图。
3. **剧本能下指令**：对白行里的行为说明不是文字标签，而是带主体、起止状态、目标、时长的动作指令，分镜与渲染真的照着执行。
4. **人与景协同**：一条逐帧时间轴统一调度人物各层、场景各层、镜头运动、口型、字幕。
5. **通用、不写死**：新增人物/场景/动作靠注册资产 + 数据；缺素材要明确报降级，不能静默出残次品。

## 2. 功能需求（FR）

| 编号 | 需求 | 验收要点 |
| --- | --- | --- |
| FR-01 | 人物动作库可注册 | 换第 4 个人物，只加资产 + 注册项，不改渲染代码 |
| FR-02 | 姿态/动作逐帧可演出 | 同一镜头内能看到姿态切换与位移，不只是嘴动 |
| FR-03 | 场景分层与锚点 | 至少 4 层，各层视差系数不同，前景可遮挡人物 |
| FR-04 | 跨场景空间移动 | 「客厅 → 厨房」在连续镜头里有位移与场景过渡，不是硬切 |
| FR-05 | 行为指令结构化 | 对白行的动作说明含 actor/verb/from/to/target/时间，可被解析与执行 |
| FR-06 | 统一逐帧调度 | 单一时间轴求值所有层，预览与成片同源 |
| FR-07 | 显式降级 | 缺资产/未注册时产出里带降级说明，禁止静默冒用他人形象或别的场景 |
| FR-08 | 保持现有能力 | 双语剧本、字幕、TTS、时长铁律、锁定/版本/任务队列不回归 |
| FR-09 | 预览可见动画 | 工作台 9:16 预览能播放出与成片一致的姿态/视差变化 |
| FR-10 | 可回归验证 | 换 3 组人物 × 3 组场景跑同一脚本，结果稳定且降级留痕 |

## 3. 非功能需求（NFR）

| 编号 | 需求 | 约束 |
| --- | --- | --- |
| NFR-01 | 导出性能 | 不得「每帧一次 Edge 截图」；用有限帧档 + 硬链接铺序列，单镜头截图次数有上限 |
| NFR-02 | 磁盘 | 逐帧序列用硬链接复用底图，不产生上百份重复 PNG |
| NFR-03 | 兼容性 | 现有 96 个测试与 typecheck 必须继续通过 |
| NFR-04 | 可回退 | 动画链路异常时自动回退现有 4 档口型链路，且在结果里告警 |
| NFR-05 | 零密钥 | 不引入在线图像/视频模型作为硬性依赖 |
| NFR-06 | 可渐进 | 动作资产可先用现有 6 视图近似，后续替换成真序列帧时代码零改动 |

## 4. 现状差距映射

| 目标 | 现状 | 差距根因 |
| --- | --- | --- |
| 人物会演 | 只贴一张 fullBody + 4 档口型 | 无动作资产、无逐帧求值 |
| 场景有空间 | 单张静态 SVG + 整帧推近 | 无分层、无锚点、无视差 |
| 剧本下指令 | action 是单标签字符串 | 无起止/目标/时长，渲染层不消费 |
| 人与景协同 | 只有 MouthShape[] 一条逐帧数据 | 无 FrameDirector、无空间坐标 |
| 换人不崩 | 3 人标定白名单、12 场景配色字典 | 内容写死在代码里，未命中静默降级 |

## 5. 明确的边界

- 本期不做：在线 AI 视频生成、LoRA 训练、3D 建模、专业非线编、多人协作、自动发布。
- 本期不要求：真实骨骼绑定或手绘逐帧素材；用现有六视图 + cutout 立绘做姿态/变换近似即可，但**必须数据驱动、可替换为真序列帧**。
- 双语、TTS、字幕、项目/分镜/任务/版本等既有功能全部保留，不做重构。

## 6. 验收口径

1. `npm run typecheck` 通过，`npm test` 通过（含新增用例）。
2. 用同一份剧本、换 3 组人物与 3 组场景分别导出，均能出片且画面随注册数据变化；未注册项在导出结果里出现降级说明。
3. 一个含「坐→站→走」的镜头，抽第 0 / 中段 / 末帧三张，姿态与人物位置必须不同（可用 PNG 哈希或像素差验证）。
4. 分层场景抽帧，远景与前景位移量不同。
5. 预览页播放的画面与成片抽帧一致。
